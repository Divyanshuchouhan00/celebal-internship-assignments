# Week 8 Assignment – AI Agent with Tool Routing

## Overview
This project implements a simple AI Agent capable of understanding user queries and routing them to the appropriate tool based on the detected intent.

## Features
- Performs mathematical calculations using a Calculator Tool.
- Extracts important keywords from text using a Keyword Extraction Tool.
- Returns structured JSON responses.
- Handles general queries with a default response.
- Includes basic error handling for invalid calculations.

## Tools Used
- Python
- Google Colab / Jupyter Notebook

## Project Workflow
1. Receive user query.
2. Detect user intent.
3. Route the query to the appropriate tool.
4. Execute the selected tool.
5. Return the response in JSON format.

## Sample Queries
- `Calculate 20 + 5`
- `Extract keywords from Artificial Intelligence is transforming industries`
- `What is Machine Learning?`

## Learning Outcomes
- Tool Calling
- Intent Detection
- Agent Routing
- Structured JSON Responses
- Basic Agentic AI Workflow
